# Activity (Oct 29 → Nov 1) — **The post-interim lull is over on both layers: [[alan-frindell|afrind]] merges eight draft-23 PRs into [[moq-transport]] (Oct-29→31), [[will-law|Will Law]] opens a five-PR MSF catalog/timeline burst, and the AUTH design team's work reaches a privacy-pass PR — while the implementations run a clear draft-22 adoption wave ahead of the ~two-weeks-out IETF 127 hackathon: [[moqtransport|Eyevinn/moqtransport]] cuts v0.15.0 (draft-22 alongside -18), [[moqlivemock]] brings its whole stack onto draft-22 (#164), [[moq-rs|cloudflare/moq-rs]] cuts v0.7.31, [[moqtail]] cuts its first relay release since July (relay@0.16.0), and [[moq-dev]] cuts v0.17.10 atop 200+ merges. The interop nightly settles off the Oct-29 spike into a 47–48% band (272/562 on Nov-1) as "ahead"/draft-22 cells creep up. Two new individual drafts surface — MoQ Feedback -01 and a volumetric-video draft-yuyou-moq-v3c-00.**

With the 10/26 interim's queue cleared, the WG's editor turned a long backlog of agreed issues into merged text, while the media-format editor opened a fresh round of catalog/timeline PRs. The headline across the implementations is uniform: everyone is lighting up **draft-22 alongside draft-18** — the interop target pair from [[interim-meetings|interim-24]] and Seattle, and the target set for the **IETF 127 hackathon** now roughly two weeks out. Slack was not checked this run.

## Spec / WG: afrind clears eight draft-23 PRs; MSF opens a catalog/timeline burst

- **[[moq-transport]] lands eight merges Oct-29 → Oct-31** (all [[alan-frindell|afrind]]; all **draft-23 material — transport stays draft-22**, no release), clearing much of the Oct interim queue:
  - [#2040](https://github.com/moq-wg/moq-transport/pull/2040) *"Describe where timeouts apply and the tradeoffs in setting them"* (+21/−0, fixes #1743).
  - [#2011](https://github.com/moq-wg/moq-transport/pull/2011) *"Identify the unsupported property in UNSUPPORTED_EXTENSION"* (+14/−0, fixes #1951) — adds an **UNSUPPORTED_PROPERTY Error Detail** carrying the Property Type of each Mandatory Track Property the sender doesn't understand.
  - [#2017](https://github.com/moq-wg/moq-transport/pull/2017) *"Use a varint length for control messages"* (+42/−21, fixes #1998) — the control-message Length becomes a **varint bounded by a new MAX_CONTROL_MESSAGE_SIZE Setup Option** (default 65535).
  - [#2013](https://github.com/moq-wg/moq-transport/pull/2013) *"Mark the end of a complete Group in FETCH"* (+8/−5, fixes #1934) — extends the End-of-Track rule to Groups via an **End of Group serialization flag**.
  - [#2018](https://github.com/moq-wg/moq-transport/pull/2018) *"Allow overlapping namespace subscriptions"* (+18/−32, fixes #1792) — **removes the prefix-overlap prohibition** for SUBSCRIBE_NAMESPACE / SUBSCRIBE_TRACKS (and the PREFIX_OVERLAP error), adding a **SUBSCRIBE_TRACKS_ID** parameter so each resulting PUBLISH identifies its SUBSCRIBE_TRACKS.
  - [#2019](https://github.com/moq-wg/moq-transport/pull/2019) *"Define the effects of updating a namespace subscription prefix"* (+14/−6, fixes #2001).
  - [#2042](https://github.com/moq-wg/moq-transport/pull/2042) *"Prohibit coalescing REQUEST_UPDATEs that contain FILL_PARAMETERS"* (+4/−1, fixes #1992).
  - [#2039](https://github.com/moq-wg/moq-transport/pull/2039) *"Treat a Property used outside its scope as a malformed Track"* (+6/−0, fixes #2028).
- **New open PRs** keep the draft-23 queue moving: [#2049](https://github.com/moq-wg/moq-transport/pull/2049) *"Default FILL_PARAMETERS Group Order to Ascending"* (afrind), [#2047](https://github.com/moq-wg/moq-transport/pull/2047) *"Rename AUTHORIZATION_TOKEN to AUTH_PAYLOAD"* ([[aman-sharma|sharmafb]]), and [#2045](https://github.com/moq-wg/moq-transport/pull/2045) *"Describe Setup Options in 0-RTT"* (afrind).
